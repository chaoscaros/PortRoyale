# 美术方向

17 世纪加勒比殖民港口，半写实策略视角，适度风格化。目标是可信的帆船与港口尺度、清楚的建筑用途和温暖海域气氛。当前为首轮视觉基础，植被和局部地形仍偏简化，不把当前低面数表现当成最终美术标准。

## 色彩与光照

深青蓝外海、青绿浅水、暖沙滩、灰泥墙、陶土红瓦、深木船体与象牙帆布。主光采用暖色方向光，冷色天光填充；建筑与船投射 PCF 阴影。天空渐变与轻雾控制远景，ACES + FXAA；不使用强 bloom/SSAO。海面采用多频波纹法线、Fresnel、高光和岸边渐变，避免大片纯色。

## 港口与环境

哈瓦那是本轮 hero 港：两类民居、仓库、总督府、教堂、灯塔、码头、桶箱小艇，棕榈/热带树/灌木；多次实例化形成城镇。沙滩—草地—丘陵有连续高度与颜色过渡。建筑保留红瓦屋顶、门窗、檐口和明确基座，不用 runtime box/cylinder 拼正式城市。道路广场属于表现层 ground。其他三港保持简化岛屿与少量共享模块，不能宣称四城精修完成。

## 船只

运行使用 sloop：收尖船首、鼓腹船体、甲板、尾舱、舵、桅杆、弯曲主帆与前帆、索具。1 单位=1 米，pivot 位于水线中心，木材与帆布使用自制 1K 纹理。观察尺度以策略镜头为主，近看需辨认船体厚度与帆面。摆动、视觉停泊朝向与尾流只属 Rendering，不改变航速和权威位置。

## UI 与镜头

深海蓝透明底、黄铜边线、象牙文字；中文主导，自制统一线性 SVG 图标，不使用 emoji。顶部游戏信息与真实时间倍率、底部镜头工具、左下舰队和右下港口信息，F3 默认隐藏调试。资金明确显示未启用，不伪造余额/日期。默认镜头展示哈瓦那与船，聚焦舰队/哈瓦那/全海图可快速找回。

## 后续验收重点

继续提升植被自然度、沙滩与礁石细节、帆布材质和其他港口；检查近中远镜头、1366/1440/1920 桌面布局及普通设备表现。素材预算服务画面质量，不以增加面数证明精细度。
