# 性能策略

渲染目标 60 FPS，时钟默认每模拟秒 10 tick；2×/4× 正常对应每真实秒 20/40 tick。性能统计一秒更新一次，HUD最多约10Hz更新。实际 FPS 随设备、窗口和负载变化，不承诺固定值。

宿主长帧最多计入 250ms，隐藏页不补算。海面是单平面 procedural shader，不开发 FFT/流体/浮力。未来大量环境使用 Instances / Thin Instances / LOD；当前不做大规模 benchmark。

引擎初始打包体积仍较大，后续可评估按需导入、资源懒加载和构建拆分；不要为消除警告改变游戏行为。

## Phase 1

当前仅4Ports/1Fleet。导航集中在FleetNavigationSystem，未来hundreds of fleets仍走集中tick，不为每舰队建立interval。舰队信息最多约10Hz更新，性能统计1Hz；标签每帧投影、航线复用mesh。未做大规模benchmark，当前不宣称性能达标。

## Task 03 视觉切片

2048 PCF 主阴影，船只与主要建筑投影；植被不批量投影。同模块多实例复用，源网格统一 receiveShadows，避免在 InstancedMesh setter 上设置而失效。海面和尾流单平面 shader，FXAA + ACES，关闭 bloom/SSAO。15个正式GLB约24.6MiB，编辑源约85.7MiB；独立GLB嵌入图片有重复，尚未做LOD/资源压缩。

修复手动 RAF 渲染未 beginFrame/endFrame 导致 Engine deltaTime 不更新、平滑聚焦无法前进的问题。模拟仍由自己的固定步长驱动。航线复用网格并保持可见性，不每帧创建新对象。

指定 Chrome 实测多次稳定读数59～60 FPS，交互采样曾短暂51 FPS；1×/2×/4× 对应约10/20/40 TPS。三档桌面视口已检查。此为当前4港1船短时观察，非低配设备或长时压力基准，不能承诺所有设备60FPS。构建仍有 Babylon 大chunk警告。

## Task04 · 英雄资产重制（历史基线）

24个运行GLB合计17,209,968 bytes（16.41MiB），20张共享PNG合计26.48MiB。编辑纹理21张1K；.blend约254MiB，保留可编辑组件与所需packed纹理，不影响运行下载。每个模块导出时按材质合并，实例共享几何/材质；图片内容哈希去重，几何保持未压缩。仍为LOD0。GLB容量降低来自移出重复图片，不代表总下载量小于Task03。

英雄船66810三角面、9材质；地标和棕榈预算例外详见资产表。主要建筑/船/棕榈投影，树林不批量投影；2048PCF、FXAA、ACES、微量Bloom，未启用SSAO。自制低频环境立方体用于补足PBR反射，没有外部HDRI。当前4港1船，次级岛在全览/近焦点可见。

最终用户Chrome原标签：默认近港约60FPS/10TPS，全览4×抵达后59FPS/40TPS；操作/镜头过渡观察52～61FPS，暂停稳定TPS0。不同采样刷新瞬间会显示混合TPS，不是模拟频率改变。三档1366×768、1440×900、1920×1080已查看正式HUD；恢复原窗口1920×878。此为当前宿主短时观察，未作低配、GPU计时、长时内存和批量舰队基准。

生产主chunk6.03MB/gzip1.30MB，build体积警告保留。后续需先保视觉质量，再按LOD、KTX2、懒加载和引擎拆包做有实测依据的优化。

## Task05 · 当前成本与实测

35个GLB共39,133,312 bytes（37.32MiB），18张共享PNG共32,920,206 bytes（31.40MiB）；35套可编辑源共393.75MiB，不进入浏览器下载。哈瓦那280个模块摆放；船67880三角面、9材质、8共享图片。颜色图集1254、地表2K、微表面1K。双UV与顶点色使几何缓冲变大，共享纹理去重不能消除顶点属性开销。清理了没有任何当前GLB引用的旧共享纹理。

保持模块实例共享几何、按材质合并、静态世界矩阵缓存；动态舰队不冻结。2048PCF、ACES、FXAA、微量Bloom。4096阴影和半分辨率AO试验未保留，AO方案约34FPS。最终当前Chrome近港/全览约44～52FPS，视口/加载过渡有33～38FPS样本；接近60的目标尚未稳定达到。低配、长时内存、GPU计时和批量舰队基准未进行。

1×/2×/4×观察约10/20/40TPS，暂停稳定0TPS。三档1366×768、1440×900、1920×1080桌面截图/面板操作已检查；恢复用户窗口。构建主chunk6.05MB/gzip1.31MB仍有体积警告。下一步先精修地形植被和材质，再基于实测做LOD、KTX2、按需加载，不以盲目降模型质量换帧率。
